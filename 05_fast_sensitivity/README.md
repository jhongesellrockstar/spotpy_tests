# Sensibilidad FAST

Ejecute `run_fast.py`. FAST transforma variaciones periódicas de cada parámetro en contribuciones espectrales (`S1`, primer orden; `ST`, total). Una sensibilidad alta significa que variar ese parámetro explica más variación de la métrica; conviene priorizarlo antes de una calibración SWAT+. No es calibración: caracteriza influencia en todo el espacio, no busca sólo un óptimo.
