# Prototipo SWAT+ IGP

No toca ni ejecuta un proyecto real. Configure los seis campos externos sólo cuando estén verificados. Cada worker futuro debe recibir una copia privada del proyecto: compartir archivos causa carreras, corrupción y resultados no reproducibles. Registre parámetros/semilla/versión, preserve fallos, aplique timeout, compruebe NaN/unidades, reinicie estado, retire warm-up y alinee fechas antes de evaluar.

Secuencia prevista: parámetros SPOTPY → copia por worker → escritura validada → `swatplus.exe` → parser verificado → warm-up → alineamiento → objetivo → siguiente conjunto.
