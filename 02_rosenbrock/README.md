# Prueba 02: Rosenbrock

`x` e `y` se exploran en `[-2,2]` y `[-1,3]`. `simulation()` devuelve ambos valores, `evaluation()` expresa el óptimo `(1,1)` y la función `(1-x)^2+100(y-x²)^2` se minimiza. Cambie sólo `REPETITIONS` en `config.py`. Ejecute `run_mc.py`, `run_sceua.py` y luego `analyse_results.py`. Cada ejecución crea un subdirectorio; no sobrescribe anteriores.
